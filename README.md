# Esthetics-Inventory-App

# CS 360 Mobile Architect & Programming Portfolio

## Project Three: Esthetics Inventory App

### 1. App Requirements and Goals

For this project, I created an inventory app for estheticians to help keep track of skincare products and supplies. I chose this idea because I understand how important it is to know what products are available and when something needs to be restocked. My goal was to create an app that would make managing inventory a little easier.

### 2. User-Centered UI Design

When designing my app, I wanted everything to be easy to find and use. I included features that allow users to view their inventory, update product quantities, and receive alerts when products are running low. I tried to keep the screens simple. When I first launched teh ap, I cold not figure out how to get the edit and delete nuttons to become visible. Turns out text I had the text color as white on a white screen.

### 3. Coding Approach

I used Java and Android Studio to build my app. I started by working on one feature at a time, but I quickly learned that even small changes could cause errors. Whenever something wasn't working, I went back through my code to see what I missed. This process helped me better understand how different parts of the app work together.

### 4. Testing and Functionality

I used the Android emulator to test my app and see if everything was working correctly. One issue I kept running into was getting the product quantities to update. I had to make several changes before it finally worked. Testing helped me catch mistakes that I wouldn't have noticed just by looking at the code.

### 5. Overcoming Challenges

The biggest challenge for me was the text message alerts. At first, they would not "send".

### 6. Demonstrating My Skills

I would say my biggest accomplishment was finally getting the inventory update feature to work. It might seem like a small part of the app, but it took a lot of troubleshooting to get there. Seeing the quantity change correctly after entering a new number was rewarding. This project definitely challenged me, but it also helped me feel more comfortable using Android Studio and working with Java.
